# Agent State Directory

This directory contains operational execution truth.

Read root `AGENT_READ_FIRST.md` first.

- `MASTER_EXECUTION_PLAN.md` — executable plan
- `GAP_LEDGER.md` — findings/gaps
- `SLICE_LEDGER.md` — node/slice status
- `CURRENT_STATE.md` — operational resumption state

Root-level master product files remain the program-wide source of truth; these files are the execution-facing mirror and must stay reconciled.
